A tiny program that writes exactly one patch-note line to
`/output/entry.txt`, announcing that human sleep has been fixed:
**Fixed: Sleep no longer requires replaying every conversation since
2014; bedtime now closes all background tabs.** The line keeps a
straight changelog face — the terse "Fixed:" opener, the confident
release-note cadence — and hides the joke in a specific repair: the
decade-long pre-sleep conversation replay is removed, and bedtime
itself now closes the background tabs. It was chosen by a
criteria-ordered tournament against the judge's published criteria
(real patch note on fixing sleep, funny on one read, genuine
changelog voice, single tight line, specific surprise). Output is
byte-exact: 112 UTF-8 bytes, no trailing newline. Run it with
`python3 main.py`.
